🔹 Ansible - Auto-healing web servers with systemd

- name: Configure Auto-healing for web serever
  hosts: all
  become: yes
  tasks: 
    - name: Ensure ngnix service is running
      service: 
         name: ngnix
         state: started
         enabled: yes
    - name: setup auto-restart for ngnix service
      lineinfile: 
          path: /etc/systemd/ngnix.service.d/override.conf
          line: 'Resart=always"
          create: yes
    
    - name: Reload systemd
      command: yes

🔹 Kubernets - Self-Healing with liveness and readingness Probes

apiVersion: apps/v1
kind: deployment
metadata: 
   name: devintekhab-web-app
spec: 
  replicas: 3
  selector: 
    matchlabels: 
       app: devintekhab-web-app
  template: 
    metadata:
      labels:
        app: devintekhab-web-app

    spec: 
     containers: 
       - name: ngnix
         image: ngnix
         ports:
           - containerPort: 80
         livenessProbe: 
             httpGet:
                path: /healthz
                port: 80
             initialDelaySeconds: 5
             periodsSeconds: 10
             readinessProbe: 
             httpGet:
                path: /healthz
                port: 80
             initialDelaySeconds: 5
             periodsSecond: 10
